# 🍔 Food Demand Analysis Project

## 📌 مشكلة العمل (Business Problem)
تعاني شركة توصيل وجبات من صعوبة في التنبؤ بطلب المواد الغذائية أسبوعياً في مراكز التعبئة المختلفة، مما يؤدي إما إلى نفاد المخزون أو هدر المواد. يهدف هذا المشروع إلى تحليل بيانات الطلب التاريخية لفهم الأنماط، وتقييم فعالية العروض التسويقية، وتقديم توصيات مبنية على البيانات لتحسين إدارة المخزون.

## 📊 أبرز النتائج (Key Results)
1. الحملات التسويقية (البريد الإلكتروني والصفحة الرئيسية) ترفع متوسط الطلب بنسبة تتجاوز 170% (ذات دلالة إحصائية p < 0.05).
2. ارتباط نسبة الخصم بالطلب ضعيف جداً (Spearman ≈ 0.158)، مما يشير إلى أن "الرؤية" أهم من "سعر الخصم".
3. تذبذب الطلب يختلف جذرياً بين فئات الوجبات، مما يستدعي استراتيجيات مخزون مخصصة لكل فئة.

## 🤖 كيف تم استخدام الذكاء الاصطناعي؟
- **GitHub Copilot**: للمساعدة في كتابة أكواد دمج الجداول (Merge) والتحقق من شروط عدم فقدان البيانات.
- **Qwen (AI Assistant)**: للمساعدة في هيكلة المشروع، صياغة ملف `AGENTS.md`، وكتابة مسودة التقرير النهائي لضمان الالتزام بشروط العميل.
- **Custom Skills**: تم إنشاء مهارات مخصصة لـ Copilot لحساب المؤشرات (Metric Calculation) وكتابة التقارير (Client Report Writing) لضمان اتساق المخرجات.

## 🚀 كيفية تشغيل المشروع
1. استنساخ المستودع: `git clone <repository-url>`
2. تثبيت المتطلبات: `pip install pandas numpy matplotlib seaborn scikit-learn`
3. وضع ملفات البيانات (`train.csv`, `meal_info.csv`, `fulfilment_center_info.csv`) في مجلد `data/raw/`.
4. فتح ملف `notebooks/data_cleaning.ipynb` وتشغيل الخلايا بالترتيب من الأعلى إلى الأسفل.
5. ستجد الرسوم البيانية المولدة تلقائياً في مجلد `reports/figures/`.

## 📂 هيكل المشروع
- `data/raw/`: بيانات المصدر (غير مدرجة في Git).
- `docs/cleaning_decisions.csv`: توثيق قرارات تنظيف البيانات.
- `notebooks/`: أكواد التحليل والتنظيف.
- `reports/`: الرسوم البيانية (PNG) والتقرير النهائي.
- `.github/skills/`: مهارات Copilot المخصصة.
